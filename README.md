# Calc Lotaje

Calculadora de posición de lotes para trading. Determina el tamaño de lote óptimo basándose en riesgo, distancia SL y multiplicador.

## Características

- Soporte para múltiples instrumentos (Oro, EUR/USD, BTC, Nasdaq, y más)
- Cambio de tema oscuro/claro
- Cambio de idioma (ES/EN)
- Vista de "más pares" con multiplicadores aproximados
- Arrastre para cerrar la hoja lateral

## Uso

1. Selecciona tu cuenta y riesgo (%)
2. Establece la distancia Stop Loss
3. Elige un multiplicador
4. El tamaño de lote se calculará automáticamente

Fórmula: `lote = riesgo / (SL × multiplicador)`
